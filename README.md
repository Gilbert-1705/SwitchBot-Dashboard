# SwitchBot Dashboard

A Home Assistant custom integration that turns the SwitchBot Weather Station into a customizable E-Ink dashboard.

## Status

🚧 Early development (v0.9-alpha)

## Planned Features

- Live Home Assistant widgets
- Weather
- Power consumption
- Nuki door lock
- Balcony door status
- Waste collection reminders
- Smart refresh
- Config Flow
- HACS support
